# Known issues en tips

Als je een fout tegenkomt in de validatietool, raadpleeg dan eerst de onderstaande lijst met bekende problemen. Een fout die niet is afgehandeld, wordt in de resultaten weergegeven bij 'Error' en begint met 'Python Exception:'.

Onderstaande tabel bevat een overzicht van bekende problemen (known issues) in het gebruik van de HyDAMO-validatietool. Waar mogelijk is een tijdelijke oplossing (workaround) beschreven. Als dat niet mogelijk is, wordt het probleem zo snel mogelijk in een nieuwe release opgelost.

|  **Nummer**    |  **Omschrijving**   |  **Toelichting/Workaround**    |  **Opgelost**    |
|:---------------|:--------------------|--------------------------------|:-----------------|
| VAL-1 | Een GeoPackage-dataset wordt niet geaccepteerd door de validatiemodule. | Een veelgemaakte fout is dat de laagnaam bij het aanmaken van een GeoPackage-bestand niet correct wordt ingesteld. De laagnaam moet voldoen aan de objectdefinitie van het gekozen [HyDAMO-datamodel (bijvoorbeeld versie 2.4 of 2.5)](https://github.com/HetWaterschapshuis/HyDAMOValidatiehandboek/tree/main/validation_schemas/datamodellen_hydamo){ target="_blank" }. <br/> Gebruik daarom altijd vóóraf de [HyDAMO wasmachine](https://github.com/HetWaterschapshuis/HyDAMOValidatiehandboek/tree/main/hydamo_wasmachine){ target="_blank" } om je GeoPackages conform bijvoorbeeld HyDAMO 2.4 of 2.5 aan te leveren. <br/> Ter inspiratie kun je de [test-set van Waterschap Rijn en Ijssel](https://github.com/HetWaterschapshuis/HyDAMOValidatieModule/blob/main/tests/data/tasks/test_wrij/datasets/HyDAMO.gpkg) bekijken. | |
| VAL-2 | Een GeoPackage-dataset veroorzaakt tijdens de validatie de foutmelding 'Python Exception'. *Success* zal op *false* staan en *Status* waarschijnlijk op *syntax-validation (fields)*. | Een of meer datasetlagen voldoen niet aan de specificaties van HyDAMO. Let daarbij specifiek op: <br/><ul><li>naam van de laag (zie VAL-1)</li><li>naam van de attributen</li><li>datatype van de attributen (integer, float, datetime, etc.)</li></ul><br/>Gebruik daarom altijd vooraf de [HyDAMO wasmachine](https://github.com/HetWaterschapshuis/HyDAMOValidatiehandboek/tree/main/hydamo_wasmachine){ target="_blank" } om je GeoPackages conform het gekozen [HyDAMO datamodel](https://github.com/HetWaterschapshuis/HyDAMOValidatiehandboek/tree/main/validation_schemas/datamodellen_hydamo){ target="_blank" } aan te leveren.  | |
| VAL-3 | In het resultaat ontbreken kolommen. Bijvoorbeeld general\_001\_*result\_variable,* waarbij *result\_variable* in de validationrules.json is gespecificeerd. | In de [Resultaten](../Aan%20de%20slag/05%20Resultaten%20interpreteren.md) zal bij errors een melding worden gegeven dat deze kolom mist met toelichting in de volgende vorm: <br/> *"general\_rule niet uitgevoerd. Inspecteer de invoer voor deze regel: (####)"* <br/> In #### vind je het regelnummer, de invoer en de Python-exceptie waardoor de regel is mislukt. <br/> De Python-exceptie vermeldt de oorzaak van de fout. Deze wijst op een onjuiste configuratie van de brondata. | In Validatiemodule 1.1.0 |
| VAL-4 | Bij gebruik van de webclient komt het regelmatig voor dat het downloaden van het resultaat de eerste keer niet lukt. | Selecteer de taak voordat je op de downloadknop klikt. Wacht totdat de velden met de dataset en validatieregels geheel geladen zijn. | |
| VAL-5 | Hele grote GeoPackage-bestanden geven problemen bij het downloaden. Tot nu toe is dit alleen vastgesteld bij datasets van het GKW. | De fout treedt op bij het aanmaken van een CSV-bestand. Gebruik als tijdelijke oplossing de API om het resultaat als GeoPackage te downloaden. | |
| VAL-6 | Zeer grote datasets (bijvoorbeeld datasets van heel Nederland) worden niet volledig verwerkt. | Bij extreem grote datasets loopt het beschikbare geheugen in de cloud vol. Probeer validaties per validatieregel uit te voeren. | |
| VAL-7| De HyDAMO wasmachine kan tegen een issue aan lopen bij gebruik van FME Desktop 2023. In de 2022 en 2024 versie zijn geen problemen bekend. Het probleem doet zich voor in de Aggregator-functie |  | Wasmachine|
| VAL-8| Bestanden met resultaten van grote gebieden met veel objecten, kunnen mogelijk niet gedownload worden via de API. | Er wordt gewerkt aan een patch om dit probleem op te lossen. Tot die tijd adviseren we om het gebied op te delen in kleinere gebieden. | In behandeling |

Je kunt problemen melden via: [hydamo-validatietool@hetwaterschapshuis.nl](mailto:hydamo-validatietool@hetwaterschapshuis.nl) of als *issue* toevoegen aan de openbare repository van de [validatiemodule](https://github.com/HetWaterschapshuis/HyDAMOValidatieModule/issues){ target="_blank" }.
